## 本次变更

### 背景

OpenPaint 0.1.x 走通了"画一笔 → 保存到图库"的最小闭环，但用户面对一张白纸时
仍需自带"图标 / 调色板 / 渐变 / 画刷"四类素材。本迭代（W9 + W10 + W11）
把这四类素材全部内嵌为**开箱即用资产**，并把 Hermes Agent 编排成
"用户口述关键词 → 自动调用 MCP 资产工具"。

安装包增量目标 ≤ 3 MB，AI 杠杆率最大化。

### 新增能力

#### 1. 资产库（W9 + W10）

- **图标（Iconify 集成）**：6 套 × 4000+ 候选（Lucide / Heroicons / Tabler /
  Material Symbols / Phosphor / Iconoir）。`search_icons` 按关键词 + 分类 +
  prefix 过滤；`render_icon_svg` 渲染为完整可粘贴的 SVG（带本地缓存 + 24h
  持久化）。
- **画刷**：8 个内置 PNG（256×256，硬圆 / 软笔 / 粉笔 / 喷漆 / 水彩 /
  油画 / 马克笔 / 模糊），前端 8 宫格缩略图；点击切换 + 调色板色条。
- **调色板**：4 套 10 色（Material / Tailwind / Pastel / Mono）。两种应用模式：
  - `swatch_bar`：在图层底部追加 32px 色条（不破坏现有像素）
  - `replace_color`：HSV 距离替换图层主色像素
- **渐变**：16 个预设（8 线性 + 5 径向 + 3 锥形）。resvg 0.48 渲染 →
  `paste_image_to_layer` 路径写回。

#### 2. AI 编排（W11-A4）

`SVG_SYSTEM_PROMPT` 末尾追加《资产库触发指引》段落，让 LLM 在用户提到
「图标 / 渐变 / 调色板 / 画刷」时优先返回 MCP 工具调用指令而不是手写 SVG。
MCP 工具描述全部补充中文 hint，便于国产 LLM 准确命中。

新增 `create_brush_from_prompt` stub（MCP 注册 14 → 15 个工具），
v0.2 调用固定返回 `{ status: "not_implemented" }`，前端 ToolCallCard 展示
"v0.3 上线"提示。

#### 3. 离线兜底 + CDN 镜像（W11-A2 / B1 / B2 / B3）

- `icon_commands::fetch_icon_from_api` 根据 `AssetsConfig.cdn_mirror` 选
  `default` / `jsdelivr` / `fastly` 镜像。
- 每次缓存未命中远程拉取后，fire-and-forget HEAD 探测 `api.iconify.design`
  可达性（10s 超时 + 30s 节流），结果写到 `~/.openpaint/asset-state.json`。
- 新增 IPC `get_asset_state` / `get_assets_config` / `set_assets_config`。
- 前端 `useAssets.isOnline` 暴露在线状态；离线时面板顶部显示「⚠️ 离线模式」
  提示。`useAssetsConfig.setCdnMirror` 切换后立即持久化。
- 设置 → 资源：CDN 镜像 3 选 1；关于：第三方资源署名页（6 套图标集 +
  License + 是否需署名）。

#### 4. 本地遥测（W11-A1）

`~/.openpaint/telemetry/assets.json` 累计 6 个事件计数（search_icons /
search_icons_cache_hit / import_icon / apply_palette / apply_gradient /
brush_switch），前端在关键操作处调 `record_asset_event`。
**仅本地追加，不外发**。

#### 5. 首次启动资源署名提示（W11-B4）

`useOnboarding.shouldShowAttributionToast` 首次启动展示「本应用使用 Lucide /
Material Symbols 等开源图标，详见 设置 → 关于」toast；dismiss 后写
`attribution_notice_shown=true`（localStorage + Rust config 双向同步），
下次不再弹。

### 设计权衡

| 维度          | 选择                                                                      | 理由                           |
| ------------- | ------------------------------------------------------------------------- | ------------------------------ |
| 画刷 PNG 数量 | 8 个 256×256                                                              | < 500 KB；后期用户可 AI 生成   |
| 调色板数量    | 4 套 10 色                                                                | 覆盖主流风格；太多反而选择疲劳 |
| 渐变类型      | 8 linear + 5 radial + 3 conic                                             | conic 视觉新但用例少           |
| MCP 工具数    | 12 → 15（apply_palette / apply_gradient / create_brush_from_prompt stub） | 1 个 stub 给 v0.3 占位         |
| 离线检测频率  | 30s 节流                                                                  | 避免每次图标渲染都发起 HEAD    |
| CDN 默认值    | `default`（api.iconify.design）                                           | 用户可手动切 jsdelivr          |
| 资源署名时机  | 首次启动 toast（一次性）                                                  | 比"每次更新都弹"友好           |
| 资源遥测粒度  | 6 个事件计数器                                                            | 不含个人标识符，隐私友好       |

## 已知小问题（不阻塞）

- `assets/brushes/*.png` 是 256×256 RGBA 占位（纯灰度衰减），不是真实笔刷纹理
  → v0.3 接 `create_brush_from_prompt` 后可用 AI 生成真实画刷
- `apply_palette::replace_color` 暂不支持多色替换（HSV 距离只针对首色）→ v0.3 多色
- 资源遥测只是本地文件，**没有可视化面板** → v0.3 设置 → 诊断 tab
- 在线 / 离线状态不会主动 push 到前端，只在 `render_icon_svg` 拉取后更新 → v0.3
  改成 `event-emit`
