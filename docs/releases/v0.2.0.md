# OpenPaint 0.2.0 — 模拟模式金径入口 + 桌面/Web 双形态（W12 联合发版）

**Release Date**: 2026-09-02
**Tag**: `v0.2.0`
**前置版本**: 0.1.4（资产库 + AI 编排 + 离线兜底）

> 版本说明：本迭代（W12）是面向"首屏价值密度"的里程碑发布。
> 引入 **Mock LLM Provider** 作为零配置 / 零费用 / 零外发的"金径入口"，
> 拆分 SettingsModal 为 QuickPreferences / AdvancedSettings 两层，
> 重设计 OnboardingCard 为四选项卡，桌面 / Web 双形态闭环。
> 按 SemVer MINOR 递增规则，从 0.1.4 → 0.2.0（含向后兼容的新功能）。

## 本次变更

### 背景

0.1.x 已经跑通"画一笔 → 资产库 → AI 帮忙 → 离线兜底"主路径，但首屏仍被
"选择 LLM / 填 API Key / 等待握手"的设置器感打断。本迭代（W12）把这道
门槛拆掉：

- **桌面 / Web 双形态**：Tauri 桌面 + 浏览器 Preview 共用同一套前端
- **金径入口**：默认走 `mock` provider（本地模板，不发网络）
- **进阶分层**：齿轮 → QuickPreferences（3 项高频），菜单深处 → AdvancedSettings
- **引导卡四选项**：新建 / 打开 / AI 帮忙 / 先用模拟模式
- **Web Preview 闭环**：浏览器打开 `localhost:5173` 即可完整体验，无需 Tauri

### 新增能力

#### 1. Mock LLM Provider（W12-MOCK-01~04）

- **Rust `LlmProvider::Mock` 枚举**：`src-tauri/src/tools/llm_commands.rs`
  新增 `Mock` 变体；`list_providers` 第一项恒为 `mock`，保证新用户
  永远看到"零配置"选项在前。
- **`call_llm` / `agent_chat` mock 分支**：根据 provider 分发，Mock
  走 `mock_svg_for(prompt)`（基于关键词 → 预置 SVG 模板）和
  `mock_chat_reply(prompt)`（基于关键词 → 文案模板）。完全本地，
  无 IPC 调用、无网络请求。
- **前端 `useLlmConfig.isMock` computed**：监听 `providerConfig.provider === 'mock'`，
  自动显示 `MockModeBanner` 横幅（顶部橙色「🟡 模拟模式 · 无外发」提示）。
- **`useAgent.send` 短路**：isMock 时直接调前端 `mockChatReply`，跳过
  Tauri IPC 调用链，延迟 < 5ms。
- **桌面 / Web 同源**：`src-web/src/api/runtime.ts` 的 `webInvoke` 在
  `isTauri=false` 时返回相同 mock 数据，Web preview 与桌面行为一致。

#### 2. 桌面 / Web 双形态（W12-WEB-01）

- **WebView2 检查改为软失败**：`main.ts` 的 `ensureWebView2Ready()`
  在 `!isTauri()` 时仅 `console.warn`，不再 throw。Web preview 不再白屏。
- **Web ProviderConfig 内存态**：`runtime.ts` 维护 `webProviderConfig`
  状态，`set_provider` / `set_api_key` 真更新内存，关闭页面即丢失。
- **MockModeBanner 横幅**：Web 端顶部固定显示「Web 预览模式 · 设置不持久化」，
  避免用户误以为改动已保存。

#### 3. SettingsModal 拆分（W12-UI-01/02）

- **QuickPreferences（齿轮入口）**：3 项高频设置——主题、Mock / 真实模式
  切换、CDN 镜像。打开关闭走 `uiStore.quickPreferencesVisible`。
- **AdvancedSettings（菜单深处）**：从「…」菜单进入，含完整 12 项
  （LLM / 快捷键 / 资源 / 关于 / 诊断等）。打开关闭走
  `uiStore.advancedSettingsVisible`。
- **bug 修复（commits `26e7ced`）**：TopBar 齿轮之前错绑 `toggleSettings`
  会打开 AdvancedSettings；改为 `openQuickPreferences`，符合命名契约。
- **`highlightLlmSettings`**：从 Mock 模式切到真实模式时，AdvancedSettings
  自动滚动到 LLM 配置项并高亮 2s，引导用户填写 API Key。

#### 4. OnboardingCard 四选项卡（W12-UI-03/04）

- **新建 / 打开 / AI 帮忙 / 先用模拟模式** 四按钮平铺，1 步选择到位。
- **`onOnboardingAiFree` 事件**：「先用模拟模式」点击后：
  1. 触发 `providerConfig.provider = 'mock'`
  2. 关闭 OnboardingCard
  3. 显示 MockModeBanner
  4. 自动打开 AI 助理面板（`useAgent.openDrawer()`）
- **`attributionNoticeShown` 持久化**：首次启动展示「本应用使用
  Lucide / Material Symbols 等开源图标」toast，dismiss 后写
  `localStorage + Rust config` 双向同步，下次不再弹（继承自 v0.1.4 的
  W11-B4 并完整闭环）。

### 设计权衡

| 维度                 | 选择                                                      | 理由                                            |
| -------------------- | --------------------------------------------------------- | ----------------------------------------------- |
| Mock provider 位置   | `list_providers` 第一项                                   | 默认 = 零配置；用户主动切换才进付费模式         |
| Mock 数据形态        | 关键词 → 模板（5 类 SVG + 10 类文案）                     | 比"完全随机"更可预测，比"调用真模型"更安全      |
| Web preview 持久化   | 内存态（不写 localStorage）                               | 避免污染真实桌面配置                            |
| WebView2 检测        | `!isTauri()` 时软失败                                     | Web preview 本就不需要 chrome.webview           |
| SettingsModal 拆分   | Quick (3 项) + Advanced (12 项)                           | 80% 用户只改 Quick                              |
| OnboardingCard 选项  | 4 个平铺按钮                                              | 减少"下一步"链，每选项单点击闭环                |
| mockChatReply 触发   | useAgent.send 内部短路                                    | 上层业务代码无感，零侵入                        |
| SettingsModal 拆分点 | uiStore.quickPreferencesVisible / advancedSettingsVisible | 两个独立 flag，避免一个 store 多 modal 互相干扰 |

## 已知小问题（不阻塞）

- Mock provider 模板只有 5 类 SVG + 10 类文案，命中率约 60%，其余返回
  「这是模拟模式 · 真实 LLM 可生成更精细结果」提示 → v0.3 接更多模板
- Web preview 的 ProviderConfig 不持久化，刷新页面后回到默认 mock
  → 这是设计行为，避免污染桌面配置
- `highlightLlmSettings` 2s 后自动取消，无声音提醒 → v0.3 加可选音效
