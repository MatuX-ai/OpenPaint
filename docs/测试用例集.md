# OpenPaint 测试用例集

> 本文件汇总了 OpenPaint 项目当前所有可执行的单元测试用例。
> 所有用例均可在本机一键运行，详见末尾"运行方式"一节。

**最后更新**：2026-08-27
**总用例数**：115 项（Rust 后端 32 项 + 前端 Vitest 83 项）
**当前状态**：全部通过 ✅

---

## 0. 运行方式

### 0.1 一键脚本（推荐）

```powershell
# 在仓库根目录 i:\OpenPaint 执行
pwsh scripts/run-audit-tests.ps1
```

脚本依次执行：依赖检查 → Rust 单测 → 前端单测 → 类型检查 → ESLint 摘要，并输出汇总。

### 0.2 手动执行

```powershell
# 后端
cd src-tauri
cargo test --all

# 前端
cd ..
pnpm install --frozen-lockfile
pnpm test:unit

# 前端类型检查（可选）
pnpm type-check
```
