### 8.1 运行说明

```powershell
# 在仓库根目录 i:\OpenPaint 执行
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\run-audit-tests.ps1
```

支持参数：

- `-SkipRust`：跳过 Rust 测试
- `-SkipWeb`：跳过所有前端阶段
- `-LogDir <path>`：自定义日志目录（默认 `.audit-logs/`）

### 8.2 已知脚本修复

- 脚本原先 `Start-Process -FilePath 'pnpm'` 在 PowerShell 5.1 下失败（pnpm 通过 corepack shim 为 `.cmd` / `.ps1`，无法被 Start-Process 直接执行）。
- 现已将 pnpm 调用统一改为 `cmd.exe /d /s /c pnpm <args>`，借助 cmd.exe 完成 shim 解析，兼容 PS 5.1。
- Rust 调用通过 `Start-Process -FilePath 'cargo'` 直接调用 `.exe` 不受影响。
