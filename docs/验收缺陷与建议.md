## 2. 已修复（本次审计过程）

| ID | 模块 | 描述 | 修复方式 | 状态 |
| --- | --- | --- | --- | --- |
| **R-F01** | 审计脚本 | `Start-Process -FilePath 'pnpm'` 在 PS 5.1 下报错 "%1 is not a valid Win32 application" | 将 pnpm 调用统一改为 `cmd.exe /d /s /c pnpm <args>`，借助 cmd.exe 解析 corepack shim；同时抽出 `Invoke-AuditStep` 公共函数消除重复 | 已修复 ✅ |

| **R-F03** | 文档 | 测试用例编号不统一 | 在 `docs/测试用例集.md` 中统一为 `TC-{模块缩写}-{三位序号}` 规范 | 已修复 ✅ |

## 4. 安全 / 隐私关注（建议评估）

| ID | 维度 | 描述 | 建议 |
| --- | --- | --- | --- |
| **R-S01** | LLM API Key | 当前 key 通过 `default_config.yaml` 字段读取 | 引入系统 keychain（Tauri `tauri-plugin-stronghold` 或 OS 凭据）；明文 YAML 仅作占位 |
| **R-S02** | 图库文件 | SQLite + 缩略图全部存放 `~/.openpaint`，未加密 | 文档化备份建议；后续可加本地加密（`sqlite-rs` + AES-GCM） |
| **R-S03** | 截图上传 | "截图→AI"链路可能含敏感内容 | UI 上明确"发送前预览"；AI 引擎设置中支持"本地 LLM 优先"（Ollama） |
| **R-S04** | MCP 子进程 | `bin/mcp.rs` 通过 stdio 与父进程通信 | 当前为受信 Rust 二进制；如未来允许第三方 MCP，需做签名校验 |
| **R-S05** | 代码签名 | macOS / Windows 端缺 EV 证书 | 与 R-A06 一并解决 |
